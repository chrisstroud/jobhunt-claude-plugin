# JobHunt for Claude

Your AI, working your job hunt. This plugin connects Claude to [JobHunt](https://jobhunt.app): it saves postings, tailors resumes and cover letters from your own facts, and tracks every application, task and interview, in the same account you use on the web.

## Install

In Claude Code:

```
/plugin marketplace add chrisstroud/jobhunt-claude-plugin
/plugin install job-hunt@jobhunt
```

The first time a JobHunt tool runs, you sign in to JobHunt in your browser (OAuth). There is no API key to copy.

## What's inside

- **MCP server:** `https://jobhunt.app/mcp`, the same tools JobHunt offers in every AI it works with.
- **Skill:** `jobhunt-tools`, a short reference card so Claude uses the tools well (orient first, name records plainly, record a submission only when you say you applied).

## How we build it

Small, reliable tools; your words and facts, never invented ones; nothing sent to an employer on your behalf. Read more at [jobhunt.app](https://jobhunt.app).
